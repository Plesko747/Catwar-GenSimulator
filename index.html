Точная вероятность

Настрой желаемые комбинации в блоках. При необходимости включи неприемлемые блоки для сравнения.

Отметь один или несколько режимов. Для всех применяются одинаковые условия блоков.

💾 Сохранённые условия

Сохраняй выбранные режимы и диапазоны блоков, чтобы быстро использовать их снова.

✅ Желаемые комбинации

Внутри блока условия действуют вместе («И»), между блоками — «ИЛИ». Пустые диапазоны не учитываются.

Внутри блока условия объединяются через «И», между блоками — через «ИЛИ». Пустые диапазоны не учитываются.

❔ Что означает КПД?

КПД сравнивает общий шанс желаемых комбинаций с общим шансом неприемлемых. Чем выше значение, тем благоприятнее соотношение. Если КПД ниже 1, неприемлемые комбинации вероятнее желаемых.

Если желаемые и неприемлемые условия пересекаются, конфликтующие блоки выделяются красным, а КПД не показывается.

Вероятность = количество подходящих комбинаций / количество всех допустимых комбинаций выбранного режима × 100%. Каждая допустимая комбинация считается равновероятной. Реальные вероятности CatWar могут отличаться.
