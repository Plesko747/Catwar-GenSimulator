# CatWar — Симулятор боевых параметров

## Функции

- 8 режимов генерации, 5 первичных параметров, сумма строго 100,0%, шаг 0,1%.
- Пять случайно перемешанных карточек с постепенным открытием.
- Локальная коллекция до 500 комбинаций, названия, сортировка, фильтр, копирование.
- Расчёт шансов до 100 000 симуляций, прогресс, остановка, история до 100 записей.
- Тёмная и светлая темы, настройки анимаций и звуков.
