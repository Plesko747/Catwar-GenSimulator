# CatWar — Симулятор боевых параметров

Неофициальный фанатский симулятор. Статический сайт: HTML, CSS, JavaScript, Web Worker. Сервер, аккаунты и внешние библиотеки не требуются.

## Запуск

1. Распакуйте архив.
2. Для корректной работы Web Worker откройте проект через локальный HTTP-сервер: `python -m http.server 8000` в папке проекта, затем перейдите на `http://localhost:8000`.
3. Или загрузите файлы **в корень репозитория GitHub** и включите **Settings → Pages → Deploy from a branch → main / (root)**. После публикации сайт доступен по адресу, указанному GitHub Pages.

## Функции

- 8 режимов генерации, 5 первичных параметров, сумма строго 100,0%, шаг 0,1%.
- Пять случайно перемешанных карточек с постепенным открытием.
- Минутный интервал между обычными генерациями.
- Локальная коллекция до 500 комбинаций, названия, сортировка, фильтр, копирование.
- Расчёт шансов до 100 000 симуляций, прогресс, остановка, история до 100 записей.
- Минутный интервал между запусками расчётов (не между попытками внутри расчёта).
- Тёмная и светлая темы, настройки анимаций и звуков.
- localStorage, резервные копии JSON.

## О точности

Алгоритм выбирает равновероятные целочисленные разбиения 1000 десятых процента на пять параметров (случайные разделители). Для режимов с уклоном используется отбор подходящих разбиений, для баланса — равновероятное распределение оставшихся 25,0% сверх гарантированных 15,0% каждому. Это **модель симулятора**, а не доказанная реализация алгоритма игры catwar.net. Вероятности в калькуляторе относятся к этой модели.

Данные остаются в браузере. Не очищайте данные сайта без резервной копии.
